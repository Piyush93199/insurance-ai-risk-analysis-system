# Day 19 Interactive Dashboard Enhancements

## Objective

The objective of Day 19 was to improve dashboard interactivity, navigation, and usability by implementing user-friendly dashboard components and interactive analytical sections.

The focus was on creating a more organized and professional dashboard experience while improving accessibility to project information and analytics.

---

# Overview

As the dashboard continued to grow with prediction modules, analytics visualizations, and business intelligence features, it became necessary to improve navigation and content organization.

Several interactive components were introduced to enhance usability and provide a cleaner user experience.

---

# Enhancements Implemented

## 1. Sidebar Navigation System

A navigation menu was implemented using Streamlit sidebar controls.

### Navigation Sections

* Risk Prediction
* Analytics Dashboard
* Project Information

### Purpose

* Improve dashboard organization
* Simplify navigation
* Separate dashboard functionalities

### Benefits

* Better user experience
* Cleaner dashboard layout
* Improved accessibility

---

## 2. Project Information Module

A dedicated project information section was introduced.

### Information Displayed

* Project overview
* Technology stack
* Model details
* System capabilities

### Technology Stack

* Python
* Pandas
* NumPy
* Scikit-Learn
* Random Forest Classifier
* Joblib
* Streamlit

### Benefits

* Provides project context
* Improves documentation visibility
* Enhances project presentation quality

---

## 3. Expandable Analytics Components

Analytics sections were converted into expandable panels.

### Implemented Sections

#### Risk Distribution Analysis

Displays customer distribution across risk categories.

#### Customer Segmentation

Displays smoker and non-smoker segmentation analysis.

#### Model Performance

Displays machine learning evaluation metrics.

#### Business Insights

Displays insurance-related business intelligence findings.

#### Dataset Explorer

Displays dataset feature information.

#### Customer Risk Insights

Displays important risk-driving factors.

### Benefits

* Reduces dashboard clutter
* Improves readability
* Allows selective content exploration

---

## 4. Dataset Explorer

An interactive dataset explorer was introduced.

### Features Displayed

| Feature  | Type        |
| -------- | ----------- |
| Age      | Numeric     |
| Sex      | Categorical |
| BMI      | Numeric     |
| Children | Numeric     |
| Smoker   | Categorical |
| Region   | Categorical |

### Benefits

* Improves dataset understanding
* Useful for demonstrations
* Supports project documentation

---

## 5. Customer Risk Insights

A dedicated section was added to explain major risk factors used by the model.

### Key Risk Drivers

* Smoking Status
* BMI
* Age
* Number of Children

### Additional Insights

High-risk customers generally exhibit:

* Smoking behavior
* Higher BMI values
* Increased claim probability
* Greater insurance costs

### Benefits

* Improves model interpretability
* Enhances decision support
* Provides business understanding
